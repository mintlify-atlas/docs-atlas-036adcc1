Some games transcend their era. The classics section of CXSHS Game Hub collects the titles that defined browser gaming and remain as compelling today as the day they launched — alongside several legendary games that pre-date the internet entirely but belong in every game collection. Every file in this section is fully self-contained and offline, meaning Pac-Man plays identically whether you have a network connection or not, and your Minecraft world generates locally without contacting any server.

## Minecraft — All Eight Versions

The CXSHS Game Hub includes eight separate Minecraft versions, covering the entire early-access period from the very first playable build through the polished 1.12 release. Two versions come in both standard JavaScript and optimized WebAssembly (WASM) builds.

<Tabs>
  <Tab title="Classic Era">
    ### Indev
    The earliest publicly available Minecraft build. Blocky world generation, basic survival loop, and the original inventory system that long-time fans still remember fondly. Open `Indev.html` to play.

    ### Alpha 1.2.6
    The Alpha phase introduced proper survival with hunger, multiplayer, and the first biome variety. This is the version many older players remember as their introduction to Minecraft. Open `Alpha_1.2.6.html` to play.

    ### Beta 1.3
    Beta brought improved world generation, weather effects, and the foundations of the crafting system players know today. Open `Beta_1.3.html` to play.
  </Tab>
  <Tab title="Release Era">
    ### Version 1.5 — The Redstone Update
    The Redstone Update overhauled circuit mechanics with comparators, droppers, and daylight sensors. Standard JavaScript build. — `1.5.html`

    ### Version 1.8 — The Bountiful Update
    Introduced ocean monuments, banners, armor stands, and spectator mode. Two builds are available:
    - `1.8.html` — Standard JavaScript build
    - `1.8_WASM.html` — WebAssembly build for significantly smoother performance

    ### Version 1.12 — The World of Color Update
    Added concrete, glazed terracotta, the advancements system, and the full color palette for blocks. The most visually complete version in the collection. Two builds are available:
    - `1.12.html` — Standard JavaScript build
    - `1.12_WASM.html` — WebAssembly build for significantly smoother performance
  </Tab>
</Tabs>

<Note>
  The **WASM builds** (`1.8_WASM.html` and `1.12_WASM.html`) compile the game engine to WebAssembly rather than JavaScript, resulting in noticeably better frame rates on most modern browsers. If your machine struggles with the standard builds, switch to the WASM variant of the same version.
</Note>
