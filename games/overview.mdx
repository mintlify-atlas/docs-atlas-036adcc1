CXSHS Game Hub ships with 352 fully self-contained HTML games stored in the `offline/` directory. Every title runs entirely in your browser with no internet connection required — each file bundles all assets inline so it can be opened directly or launched through the Hub's tabbed interface. Games are organized into five genres to help you find what you're in the mood for, and the Hub's built-in search bar lets you filter by name instantly.

## Accessing the Game Library

You can reach any game in two ways: through the **Games** section of the main Hub launcher (`index.html`), which provides a searchable grid with genre filters and a **Random** button, or by opening individual files from the `offline/` folder directly in any modern browser. Both approaches work completely offline.

## Headline Titles

The catalog spans everything from cutting-edge browser ports to timeless arcade classics. A few highlights that draw players back repeatedly:

- **Minecraft** — eight separate versions are included, from the earliest Indev build all the way through the polished 1.12 release, with WebAssembly variants for 1.8 and 1.12.
- **Friday Night Funkin** — the full rhythm-battle experience in a single HTML file.
- **Slope** — the punishing high-speed 3D ball-rolling game that never gets old.
- **Geometry Dash** — rhythm-based platforming with tight controls.
- **Cookie Clicker** — the original idle clicking sensation.
- **2048** — the addictive sliding-tile number puzzle.
- **Pac-Man** — the authentic arcade maze game, offline forever.
