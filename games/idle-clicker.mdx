Idle and clicker games occupy a special corner of the CXSHS Game Hub. They reward patience and long-term thinking rather than reflexes, generating satisfying numbers that compound over time with minimal active input. All titles in this section run entirely offline as self-contained HTML files — open one in a Hub tab, let your production scale up, and switch to another game while it runs. When you return, your numbers have grown.

## How Idle Games Work in the Hub

<Tabs>
  <Tab title="Playing in a Tab">
    CXSHS Game Hub's tabbed interface (`index.html`) lets you keep idle games running in a background tab while you play something else in the foreground. Open Cookie Clicker or Idle Breakout in one tab, then navigate to any other game in a second tab. The idle tab continues processing in the browser as long as the Hub window stays open.
  </Tab>
  <Tab title="Direct File Access">
    If you open an idle game's HTML file directly in a browser tab (e.g., `offline/cookie-clicker.htm`), it will run independently of the Hub. You can have the Hub open in one window and the idle game running in a separate browser window simultaneously.
  </Tab>
  <Tab title="Save Persistence">
    All idle games in the Hub store their save data in the browser's `localStorage` tied to the file's origin. Saves persist between browser restarts as long as you don't clear site data. Opening the same file from two different paths (via Hub vs. direct) may result in separate save slots since the origin URL differs.
  </Tab>
</Tabs>

<Tip>
  Use the Hub's built-in **Notes** app (accessible from the rail navigation in `index.html`) to log your Cookie Clicker prestige milestones, Idle Breakout ball configurations, or Idle Dice strategy notes. Notes persist in `localStorage` independently of the game saves, so your planning context stays available whenever you return.
</Tip>

<Info>
  **Cookie Clicker** (`cookie-clicker.htm`) uses a `.htm` extension rather than `.html` — make sure to open the exact filename if launching it directly from the `offline/` directory rather than through the Hub launcher.
</Info>
