The Settings panel is the central place to personalize how the CXSHS Game Hub looks and behaves. From here you can swap color themes, turn off resource-intensive animations for smoother performance, and see how many other people are browsing the hub right now. Every preference you set is written to `localStorage` and restored automatically the next time you open the hub — nothing is sent to a server by default.

## Opening Settings

You can reach the Settings panel in two ways:

<Steps>
  <Step title="Left rail shortcut">
    Click the **Settings** icon (sliders) near the bottom of the left navigation rail. The icon is always visible regardless of which view is active.
  </Step>
  <Step title="All Apps menu">
    From the hub home screen or any view, type `settings` in the address bar and press Enter — or navigate to **All Apps** and tap the **Settings** tile. Both routes open the same panel in the current tab.
  </Step>
</Steps>

## Settings Options

### Theme

The theme picker is the first section in Settings. It displays a grid of eight swatches, each showing a miniature preview of the hub's wordmark in that theme's accent color against its background. Clicking a swatch applies the theme instantly and saves it to `localStorage['gl-theme']`.

For full details on every theme's color palette, the animated ripple transition, and Halloween-exclusive features, see [Themes and Visual Customization](/customization/themes).

### Effects (Animations)

<CardGroup cols={2}>
  <Card title="What effects covers" icon="sparkles">
    Ambient canvas animations — floating ember particles, bat fly-overs, fog drift, the radial spotlight that follows your cursor, page-load burst particles, view-switch portal animations, and the theme-change wipe ripple.
  </Card>
  <Card title="How to toggle" icon="toggle-on">
    In Settings, find **Animations and effects** and click **Turn off** (or **Turn on**). The change applies immediately without a reload. The rail also has a quick-access spark icon button that toggles the same setting.
  </Card>
</CardGroup>

The preference is stored in `localStorage['gl-calm']`. When no preference exists yet (first visit), the hub checks `prefers-reduced-motion: reduce` at the OS level — users who have enabled that system-level accessibility setting start in calm mode automatically.

```js
// Simplified from index.html
function setCalm(on) {
  calmMode = on;
  document.documentElement.classList.toggle('calm', on);
  localStorage.setItem('gl-calm', on ? '1' : '0');
}
```

<Tip>
  On lower-powered Chromebooks or shared school devices, disabling effects noticeably reduces CPU usage during gameplay. The canvas animation loop exits early when `calmMode` is `true`, freeing the main thread for the game iframe.
</Tip>

### Users Online

The **Users online** section in Settings shows a live count of how many people are currently using the hub.

<Tabs>
  <Tab title="Local mode (default)">
    Out of the box, the hub counts tabs open **on your device only** using the browser's `BroadcastChannel` API (`gl-presence` channel). Each tab pings every 5 seconds; tabs that go silent are removed from the count after 12 seconds.

    The display reads: **N users online (this device)**

    This requires no external service and works fully offline.
  </Tab>
  <Tab title="Live mode (Firebase)">
    If the hub operator pastes a Firebase Realtime Database URL into the `PRESENCE_URL` constant in `index.html`, the count switches to a live cross-device tally. Each user writes a heartbeat timestamp to `/presence/<uid>.json` every 25 seconds via Firebase's REST API. Entries older than 90 seconds are pruned automatically.

    The display reads: **N users online** (no device qualifier)

    To enable this, open `index.html`, find the `PRESENCE_URL` constant near the themes section, and set it to your Firebase database URL:

    ```js
    const PRESENCE_URL = 'https://your-project-default-rtdb.firebaseio.com';
    ```
  </Tab>
</Tabs>

<Info>
  Each user is identified by a random ID stored in `localStorage['gl-uid']`. This ID is generated once per device and is never transmitted anywhere except to the optional Firebase database you control.
</Info>

## Built-in Apps

The hub includes four lightweight built-in apps accessible from the left rail or the **All Apps** screen. Each app opens in the current tab just like the settings panel.

<CardGroup cols={2}>
  <Card title="Notes" icon="note-sticky">
    A full-viewport `<textarea>` that saves every keystroke to `localStorage['gl-notes']`. Notes persist across sessions and browser restarts. No sync, no account — purely local.
  </Card>
  <Card title="Clock" icon="clock">
    Displays a live digital clock updated every 100 ms. Includes a **stopwatch** with Start/Stop and Reset controls. On the Halloween theme, a countdown to October 31 appears below the clock.
  </Card>
  <Card title="Music" icon="music">
    An offline audio player. Click **Choose songs** to load local audio files (MP3, OGG, etc.) from your device. Previous / Play-Pause / Next controls and a seek bar are provided. A mini-player in the address bar persists across tab switches via `BroadcastChannel`.
  </Card>
  <Card title="Add a Link" icon="link">
    Saves a custom shortcut tile to the hub's home screen. Enter a **Name** (up to 20 characters) and a **URL** (the `https://` prefix is added automatically if omitted). The shortcut appears in the All Apps grid and opens the URL in the browser. Custom links are stored in `localStorage`.
  </Card>
</CardGroup>

## localStorage Reference

All hub preferences are stored in your browser's `localStorage`. The table below lists every key the hub reads and writes.

| Key | Type | Description |
|---|---|---|
| `gl-theme` | string | Active theme ID (e.g. `halloween`, `blue`) |
| `gl-calm` | `"0"` / `"1"` | Effects off (`"1"`) or on (`"0"`) |
| `gl-notes` | string | Contents of the Notes app textarea |
| `gl-uid` | string | Random anonymous user ID for online presence |
| `gl-links` | JSON string | Array of custom link shortcuts added via Add a Link |

<Note>
  All preferences live exclusively in your browser's localStorage. Clearing browser data — via Settings → Clear browsing data in Chrome, or the equivalent in your browser — will reset everything to factory defaults: Halloween theme, effects on, empty notes, and a fresh anonymous user ID. There is no cloud backup.
</Note>
