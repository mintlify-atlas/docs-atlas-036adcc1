CXSHS Game Hub is a browser-style launcher that organizes 352 fully self-contained offline HTML games into a searchable, sortable grid. When you open `index.html`, the hub automatically attempts to load the game list from a local `games.json` file or the GitHub API, caching the result in `localStorage` so the library is instantly available on subsequent visits. Each game is represented by a tile showing its cover image and name, and clicking any tile opens the game in an isolated iframe within a new tab — no page reload, no internet connection required.

## How the Library Loads

The hub uses a two-stage loading strategy to populate the games grid as fast as possible.

<Steps>
  <Step title="Check the localStorage cache">
    On startup, `autoLoad()` checks `localStorage` for a previously cached game list stored under the key `gl-list`. If a valid cached list is found, the library grid is built immediately from that data — so returning users see games without any network round-trip.
  </Step>
  <Step title="Fetch an updated list in the background">
    Simultaneously, the hub tries to fetch `games.json` from the same directory. If `games.json` is unavailable or returns an error, it falls back to querying the GitHub API (`/repos/{owner}/{repo}/git/trees/HEAD?recursive=1`) and filtering for files matching `offline/*.html`. The freshest list then replaces the cache in `localStorage`.
  </Step>
  <Step title="Fall back to the folder picker">
    If both automatic methods fail — for example when running `index.html` as a local file rather than from GitHub Pages — the hub shows a **Choose games folder** button. Clicking it invokes the browser's File System Access API (or the `<input webkitdirectory>` fallback) so you can point the hub directly at the `offline/` folder on your device.
  </Step>
</Steps>

<Note>
  Files matching `SKIP_FILES` (such as `single-file.html`, `file-input.html`, `epicviewer.html`, and `index.html` itself) and directories matching `SKIP_DIRS` (such as `inline-tools/`, `methods/`, and `.github/`) are automatically excluded when loading the library, so only real game files appear in the grid.
</Note>

## Game Tiles and Cover Art

Every game in the library is displayed as a square tile. When a tile enters the visible viewport, an `IntersectionObserver` queues the game for a cover scan. The scanner reads the first 300 KB of the game's HTML file and looks for two kinds of embedded image data:

- **`og:image` meta tag** — if found and the image is at least 120 px wide, it becomes the full-bleed tile background.
- **`<link rel="icon">` tag** — if a data-URI favicon is found but no `og:image` exists, the favicon appears as a small icon centered on the tile.

If neither is found, the tile displays the game's name on a color-coded gradient background derived from a hash of the game's title. Up to four cover scans run in parallel so the grid fills in quickly as you scroll.

## Playing a Game

Clicking any game tile opens it in the **Play view** — a full-screen `<iframe>` inside a new browser-style tab. The hub toolbar remains accessible during play:

<CardGroup cols={2}>
  <Card title="Navigation Buttons" icon="arrow-left">
    Use the **Back** and **Forward** buttons in the toolbar to move through each tab's navigation history. The hub tracks a separate history stack per tab, so switching tabs never loses your position in another game.
  </Card>
  <Card title="Refresh Button" icon="rotate-right">
    Press the **Refresh** (reload) button while a game is open to fully restart it. The iframe `src` is cleared and immediately set again, giving the game a clean reload without closing the tab.
  </Card>
  <Card title="Address Bar" icon="magnifying-glass">
    The address bar shows the current location in the `cxshs://` URL scheme (for example, `cxshs://games/slope`). You can type a game name directly into the address bar and press Enter to navigate to it.
  </Card>
  <Card title="Fullscreen Button" icon="expand">
    Click the **Fullscreen** button to enter fullscreen mode. When a game is active, the button requests fullscreen on the iframe itself for a true full-screen play experience. Press Escape or click again to exit.
  </Card>
</CardGroup>

<Tip>
  Hold **Ctrl** (or **Cmd** on Mac) while clicking a game tile to open it in a new tab without leaving your current view. The hub supports up to 8 simultaneous tabs.
</Tip>
