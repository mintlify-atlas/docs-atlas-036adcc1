CXSHS Game Hub is a curated collection of 352 fully self-contained HTML games paired with a polished browser-style launcher. Every game lives in a single `.html` file inside the `offline/` folder — open it and it runs completely on-device with zero network requests, zero accounts, and zero installs required. Whether you're on a school Chromebook with restricted internet, a classroom computer without Wi-Fi, or simply want a reliable local arcade, the hub has you covered.

## Why it exists

Many school networks block game sites, throttle bandwidth, or require sign-ins that students don't have. CXSHS Game Hub sidesteps all of that. Because every game asset (graphics, audio, scripts) is inlined directly into its HTML file, the browser never needs to reach out to the internet. The launcher itself — `index.html` — is equally self-contained: tabbed browsing, search, favorites, a music player, notes, a clock, and eight color themes all work completely offline.

## How the collection is packaged

## Key facts

- **352 games** — action, puzzle, arcade, and more, each a single self-contained `.html` file.
- **No internet required** — every asset is inlined; games work fully offline once downloaded.
- **No installs or accounts** — just open `index.html` (or `single-file.html`) in any modern browser.
- **Cross-platform** — runs on Windows, macOS, Linux, and ChromeOS in any up-to-date browser.
- **Restricted-environment friendly** — designed specifically to work where typical game sites are blocked.
