## Get started

<Steps>
  <Step title="Download the repository">
    Click the **Code** button on GitHub and select **Download ZIP**. Extract the ZIP to a local folder. You can also clone with Git:
    ```bash
    git clone https://github.com/cash90954-gif/cxshgmz.git
    ```
  </Step>
  <Step title="Open the Game Hub">
    Navigate to the extracted folder and open `index.html` in your browser. The CXSHS Game Hub will boot up with the Halloween theme by default.
  </Step>
  <Step title="Pick a game and play">
    Click **Games** in the left rail, browse or search the library, and click any tile to launch the game in a new tab.
  </Step>
  <Step title="Set up for restricted environments">
    On a Chromebook or restricted network? See the [Restricted Environments](/methods/overview) guide for step-by-step instructions for your specific setup.
  </Step>
</Steps>

<Note>
  The full repository is large (~several GB due to inlined game assets). If download time is a concern, see [single-file.html](/tools/single-file) for a lighter alternative that fetches or imports games individually.
</Note>
